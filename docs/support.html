FAQ

macOS says it can’t verify the app

It can’t, and it is telling the truth. Notchy is built without an Apple Developer ID, so Apple has never checked it and macOS says so on the first open. Open System Settings → Privacy & Security, scroll down to the message naming Notchy, and click Open Anyway. That is once per Mac; every later launch is ordinary. The download page has the same steps with the terminal equivalent, and neither asks you to turn Gatekeeper off.

After updating, macOS asks to let Coucou use my keys

That’s expected once after updating from 0.1.0, which was signed differently. Enter your Mac password and click Always Allow, once for each key you saved.

Where is the Windows download?

It is paused for now. Microsoft Defender wrongly flags the unsigned Windows installer as malware; a false-positive report is under review at Microsoft, and the installer will come back once it’s cleared and signed. Until then you can build it from source.

Is there a Linux version?

Yes, in beta: an AppImage, a .deb and a .rpm for x86_64, in Coucou for Linux 0.1.1 (beta). The island sits in the bottom-right corner by default, and Settings moves it to any of the six edges and corners; that works with compositors that support layer-shell (COSMIC, KDE Plasma, Hyprland, Sway…), and on GNOME it opens as a regular window. Gemini CLI, Antigravity and the Google AI and OpenAI chat are macOS only for now. Please report anything odd in the issues.

Mochi doesn’t show my Claude Code sessions

The hooks have to be in ~/.claude/settings.json, and the button that used to put them there has been removed. Add them by hand — the event list and timeouts are in docs/INTEGRATIONS.md §1 — then start a new Claude Code session. The relay itself is still placed on disk for you at every launch, so only the settings file needs editing.

Can I use Coucou with Gemini CLI or Antigravity (agy)? (macOS)

Yes. Open Settings → Gemini CLI → Install hooks or Settings → Antigravity → Install hooks. The same backup-and-diff flow as Claude Code applies. Once installed, each gemini or agy session gets its own pill in the island.

The chat doesn’t answer

Add your API key in Settings: Settings → Anthropic API for Claude, or Settings → Chat — other providers (macOS) for Google AI (Gemini) or OpenAI. API usage is billed by the provider, separately from any subscription.

An integration pill stays grey

Check its key in Settings. Up to 4 pills can be active at once in addition to the main workspace tool — see Settings → Active pills.

What are Active pills? (macOS)

Active pills are the coding tools, agents and AI providers you declare in Settings → Active pills. The Main picker at the top lets you choose your primary workspace tool (VS Code, Cursor, Codex or Antigravity — GitHub build only). You can then add up to 4 more pills: Gemini CLI, Anthropic, Google AI, OpenAI and service integrations. An agent that sends coucou_agent in its hook payload still gets its own automatic pill regardless.

Can I use Coucou with Cursor? (macOS)

Yes, once the Claude Code hooks are in ~/.claude/settings.json (added by hand — see the question above). Claude Code started in Cursor's terminal then shows up on the Cursor pill, and its permission requests can be answered from the notch, like in VS Code. Cursor's own agent shows up too when Cursor loads Claude Code's hooks; its requests are still answered in Cursor. Pick Cursor as your Main tool if that's where you code.

Can I use Coucou with Codex? (macOS, GitHub build)

Yes. Open Settings → Codex Hooks → Install hooks. Coucou shows you the changes to ~/.codex/hooks.json before writing anything. Once installed, open Codex and run /hooks, or open Hooks in Codex's settings, to review and trust the hooks — Codex asks for this once. After that, your Codex sessions show up on the Codex pill, and permission requests show up with Allow and Deny in the notch.

Can I use Coucou with Apple Music? (macOS, GitHub build)

Yes. Open Settings → Active pills and toggle Apple Music on. The first time you use a playback control from the notch, macOS may ask you to allow Automation for Coucou — click OK. Once granted, the pill shows the current track and lets you play, pause and skip from the notch. Mochi dances while music plays.

Apple Music automation was denied

Open System Settings → Privacy & Security → Automation, find Coucou and enable the Music checkbox. You can also click Open Settings… in the Apple Music card in the notch, which takes you directly to that setting.

No sound

Check the speaker icon in the notch header and the volume in Settings.

Which model does the chat use?

On Mac, Claude Sonnet 4.6 by default (Anthropic). Switch provider and model by clicking the model name above the chat box. For Anthropic, the model can also be set in Settings → Anthropic API. Each model is billed at its own price by the provider.

Can I use Ollama or LM Studio instead of a cloud API?

Yes (macOS). Open Settings → Chat → Local models, type the server address (or leave blank for the default), and click Connect. Coucou checks that the server is reachable and lists available models. To stop using it, click Disconnect. No API key is needed; it is free: the model runs on your Mac.

Does it work without a notch?

Yes. On an iMac, a Mac mini, or a MacBook with its lid closed on an external display, Mochi sits in a small bar at the top of the main screen. With the lid open, it stays in the notch.

How do I uninstall?

The Agents settings page has been removed, and with it every button that wrote to ~/.claude/settings.json. Removing the hooks is now a manual edit: open that file and delete the Notchy entries — each is a hook whose command points at nb-hook. If you had also installed the Plan usage status line, delete the statusLine entry pointing at nb-hook too, putting back whatever statusline-previous.json holds beside nb-hook if you had a status line before Notchy. Make a copy of the file first. Then quit the app and move it to the Trash. Optionally delete ~/Library/Application Support/NotchBuddy.

On Windows: same Uninstall button for the hooks, then Windows Settings → Apps → Coucou → Uninstall. Optionally delete %LOCALAPPDATA%\Coucou.

On Linux: same Uninstall button for the hooks, then sudo apt remove coucou or sudo dnf remove coucou, or delete the AppImage. Optionally delete ~/.config/coucou, ~/.local/share/coucou, ~/.local/share/fr.louisraille.coucou and ~/.cache/coucou.

Questions fréquentes

macOS dit qu’il ne peut pas vérifier l’app

Coucou 0.1.1 et les versions suivantes sont notarisées par Apple : macOS te demande seulement de confirmer le premier lancement. Si tu as encore la 0.1.0, ouvre Réglages Système → Confidentialité et sécurité, descends et clique sur Ouvrir quand même, ou installe la dernière version.

Après la mise à jour, macOS demande d’autoriser Coucou à utiliser mes clés

C’est normal une fois après la mise à jour depuis la 0.1.0, qui était signée autrement. Tape le mot de passe de ton Mac et clique sur Toujours autoriser, une fois par clé enregistrée.

Où est le téléchargement Windows ?

Il est en pause pour le moment. Microsoft Defender détecte à tort l’installeur Windows (non signé) comme un malware ; un signalement de faux positif est en cours d’analyse chez Microsoft, et l’installeur reviendra dès que ce sera réglé et signé. En attendant, tu peux le compiler depuis le code source.

Y a-t-il une version Linux ?

Oui, en bêta : une AppImage, un .deb et un .rpm pour x86_64, dans Coucou for Linux 0.1.1 (beta). L’island se place sur le bord du haut avec les compositeurs qui gèrent layer-shell (COSMIC, KDE Plasma, Hyprland, Sway…) ; sous GNOME, elle s’ouvre dans une fenêtre normale. Gemini CLI, Antigravity et le chat avec Google AI et OpenAI sont pour l’instant réservés au Mac. Signale tout souci dans les issues.

Mochi n’affiche pas mes sessions Claude Code

Les hooks doivent être dans ~/.claude/settings.json, et le bouton qui les y mettait a été retiré. Ajoute-les à la main — la liste des événements et leurs timeouts sont dans docs/INTEGRATIONS.md §1 — puis lance une nouvelle session Claude Code. Le relais, lui, est toujours posé sur le disque à chaque lancement : seul le fichier de réglages est à éditer.

Puis-je utiliser Coucou avec Gemini CLI ou Antigravity (agy) ? (macOS)

Oui. Ouvre Réglages → Gemini CLI → Install hooks ou Réglages → Antigravity → Install hooks. Le même flux sauvegarde + diff qu’avec Claude Code s’applique. Une fois installé, chaque session gemini ou agy obtient sa propre pastille dans l’island.

Le chat ne répond pas

Ajoute ta clé d’API dans les Réglages : Réglages → Anthropic API pour Claude, ou Réglages → Chat — other providers (macOS) pour Google AI (Gemini) ou OpenAI. L’API est facturée par le fournisseur, à part de tout abonnement.

Une pastille reste grise

Vérifie sa clé dans les Réglages. Jusqu’à 4 pastilles peuvent être actives en même temps, en plus de l’outil de code principal — voir Réglages → Active pills.

Qu’est-ce que les Active pills ? (macOS)

Les Active pills sont les outils de code, agents et fournisseurs IA que tu déclares dans Réglages → Active pills. Le sélecteur Main en haut te permet de choisir ton outil principal (VS Code, Cursor, Codex ou Antigravity — version GitHub uniquement). Tu peux ensuite ajouter jusqu’à 4 pastilles supplémentaires : Gemini CLI, Anthropic, Google AI, OpenAI et des intégrations de services. Un agent qui envoie coucou_agent dans son payload obtient quand même sa pastille automatique.

Puis-je utiliser Coucou avec Cursor ? (macOS)

Oui, une fois les hooks Claude Code dans ~/.claude/settings.json (ajoutés à la main — voir la question plus haut). Claude Code lancé dans le terminal de Cursor apparaît alors sur la pastille Cursor, et tu peux répondre à ses demandes d’autorisation depuis le notch, comme dans VS Code. L’agent de Cursor apparaît aussi quand Cursor charge les hooks de Claude Code ; ses demandes se règlent encore dans Cursor. Choisis Cursor comme outil principal si c’est là que tu codes.

Puis-je utiliser Coucou avec Codex ? (macOS, version GitHub)

Oui. Ouvre Réglages → Codex Hooks → Install hooks. Coucou te montre les changements apportés à ~/.codex/hooks.json avant d’écrire quoi que ce soit. Une fois les hooks installés, ouvre Codex et tape /hooks, ou ouvre Hooks dans les réglages de l’app, pour les passer en revue et leur faire confiance — Codex ne te le demande qu’une fois. Ensuite, tes sessions Codex apparaissent sur la pastille Codex, et les demandes d’autorisation apparaissent avec Allow et Deny dans le notch.

Puis-je utiliser Coucou avec Apple Music ? (macOS, version GitHub)

Oui. Ouvre Réglages → Active pills et active Apple Music. La première fois que tu utilises un contrôle de lecture depuis le notch, macOS peut te demander d’autoriser l’Automatisation pour Coucou — clique sur OK. Une fois accordé, la pastille affiche le morceau en cours et te permet de lancer, mettre en pause et passer à la suite depuis le notch. Mochi danse pendant que la musique joue.

L’automatisation Apple Music a été refusée

Ouvre Réglages Système → Confidentialité et sécurité → Automatisation, trouve Coucou et coche la case Musique. Tu peux aussi cliquer sur Open Settings… dans la carte Apple Music du notch, qui t’y amène directement.

Pas de son

Vérifie l’icône haut-parleur dans l’en-tête du notch et le volume dans les Réglages.

Quel modèle utilise le chat ?

Sur Mac, Claude Sonnet 4.6 par défaut (Anthropic). Change de fournisseur et de modèle en cliquant sur le nom du modèle au-dessus du champ de chat. Pour Anthropic, le modèle peut aussi être défini dans Réglages → Anthropic API. Chaque modèle est facturé à son propre tarif par le fournisseur.

Puis-je utiliser Ollama ou LM Studio à la place d'une API cloud ?

Oui (macOS). Ouvre Réglages → Chat → Local models, entre l’adresse du serveur (ou laisse vide pour le défaut) et clique sur Connect. Coucou vérifie que le serveur est accessible et liste les modèles disponibles. Pour arrêter, clique sur Disconnect. Pas de clé d’API — c’est gratuit : le modèle tourne sur ton Mac.

Ça marche sans notch ?

Oui. Sur un iMac, un Mac mini ou un MacBook capot fermé branché à un écran externe, Mochi s’affiche dans une petite barre en haut de l’écran principal. Capot ouvert, il reste dans le notch.

Comment désinstaller ?

La page de réglages Agents a été retirée, et avec elle tous les boutons qui écrivaient dans ~/.claude/settings.json. Retirer les hooks se fait donc à la main : ouvre ce fichier et supprime les entrées Notchy — chacune est un hook dont la command pointe vers nb-hook. Si tu avais aussi installé le relais Plan usage, supprime également l’entrée statusLine qui pointe vers nb-hook, en remettant ce que contient statusline-previous.json à côté de nb-hook si tu avais une status line avant Notchy. Fais une copie du fichier d’abord. Puis quitte l’app et mets-la à la corbeille. Tu peux aussi supprimer ~/Library/Application Support/NotchBuddy.

Sous Windows : le même bouton Uninstall pour les hooks, puis Paramètres Windows → Applications → Coucou → Désinstaller. Tu peux aussi supprimer %LOCALAPPDATA%\Coucou.

Sous Linux : le même bouton Uninstall pour les hooks, puis sudo apt remove coucou ou sudo dnf remove coucou, ou supprime l’AppImage. Tu peux aussi supprimer ~/.config/coucou, ~/.local/share/coucou, ~/.local/share/fr.louisraille.coucou et ~/.cache/coucou.

Preguntas frecuentes

macOS dice que no puede verificar la app

No puede, y dice la verdad. Notchy se compila sin un Apple Developer ID, así que Apple nunca lo ha revisado y macOS lo avisa la primera vez. Abre Ajustes del Sistema → Privacidad y seguridad, baja hasta el mensaje que nombra a Notchy y pulsa Abrir igualmente. Es una sola vez por Mac. La página de descarga tiene los mismos pasos, y ninguno te pide desactivar Gatekeeper.

Tras actualizar, macOS pide permiso para usar mis claves

Es normal una vez al actualizar desde la 0.1.0, que iba firmada de otra forma. Escribe la contraseña de tu Mac y pulsa Permitir siempre, una vez por cada clave guardada.

¿Dónde está la descarga para Windows?

Está pausada por ahora. Microsoft Defender marca por error el instalador sin firmar como malware; hay un informe de falso positivo en revisión y el instalador volverá cuando esté resuelto y firmado. Mientras tanto puedes compilarlo desde el código fuente.

¿Hay versión para Linux?

Sí, en beta: un AppImage, un .deb y un .rpm para x86_64, en Coucou para Linux 0.1.1 (beta). La isla se coloca por defecto en la esquina inferior derecha, y los ajustes la mueven a cualquiera de los seis bordes y esquinas; eso funciona con compositores que admiten layer-shell (COSMIC, KDE Plasma, Hyprland, Sway…), y en GNOME se abre como una ventana normal. Gemini CLI, Antigravity y el chat de Google AI y OpenAI son por ahora solo de macOS.

Mochi no muestra mis sesiones de Claude Code

Abre Ajustes → Claude Code → Instalar hooks, revisa los cambios, confirma y empieza una sesión nueva de Claude Code.

¿Puedo usar Coucou con Gemini CLI o Antigravity (agy)? (macOS)

Sí. Abre Ajustes → Gemini CLI → Instalar hooks o Ajustes → Antigravity → Instalar hooks. Se aplica el mismo flujo de copia de seguridad y diferencias que con Claude Code. Una vez instalados, cada sesión de gemini o agy tiene su propia píldora en la isla.

El chat no responde

Añade tu clave de API en los ajustes: Ajustes → Anthropic API para Claude, o Ajustes → Chat — otros proveedores (macOS) para Google AI (Gemini) u OpenAI. El uso de API lo factura el proveedor, aparte de cualquier suscripción.

Una píldora de integración se queda gris

Comprueba su clave en los ajustes. Pueden estar activas hasta 4 píldoras a la vez además de la herramienta principal — mira Ajustes → Píldoras activas.

¿Qué son las píldoras activas? (macOS)

Son las herramientas de programación, los agentes y los proveedores de IA que declaras en Ajustes → Píldoras activas. El selector Principal de arriba elige tu herramienta de trabajo principal (VS Code, Cursor, Codex o Antigravity — solo en la versión de GitHub). Después puedes añadir hasta 4 píldoras más. Un agente que envíe coucou_agent en su hook sigue teniendo su píldora automática de todos modos.

¿Puedo usar Coucou con Cursor? (macOS)

Sí. Instala los hooks de Claude Code (Ajustes → Claude Code → Instalar hooks). Claude Code arrancado en la terminal de Cursor aparece entonces en la píldora de Cursor, y sus peticiones de permiso se responden desde el notch, igual que en VS Code. El agente propio de Cursor también aparece cuando Cursor carga los hooks de Claude Code; sus peticiones se siguen respondiendo en Cursor.

¿Puedo usar Coucou con Codex? (macOS, versión de GitHub)

Sí. Abre Ajustes → Codex Hooks → Instalar hooks. Coucou te enseña los cambios en ~/.codex/hooks.json antes de escribir nada. Una vez instalados, abre Codex y ejecuta /hooks, o abre Hooks en sus ajustes, para revisarlos y confiar en ellos — Codex lo pide una vez. Después, tus sesiones de Codex aparecen en la píldora de Codex, y las peticiones de permiso llegan con Permitir y Denegar al notch.

¿Puedo usar Coucou con Apple Music? (macOS, versión de GitHub)

Sí. Abre Ajustes → Píldoras activas y enciende Apple Music. La primera vez que uses un control de reproducción desde el notch, macOS puede pedirte que permitas la Automatización — pulsa OK. Luego la píldora muestra la pista actual y permite reproducir, pausar y saltar desde el notch. Mochi baila mientras suena la música.

Se denegó la automatización de Apple Music

Abre Ajustes del Sistema → Privacidad y seguridad → Automatización, busca Coucou y marca la casilla de Música. También puedes pulsar Abrir ajustes… en la tarjeta de Apple Music del notch, que te lleva directamente ahí.

No hay sonido

Comprueba el icono del altavoz en la cabecera del notch y el volumen en los ajustes.

¿Qué modelo usa el chat?

En Mac, Claude Sonnet 4.6 por defecto (Anthropic). Cambia de proveedor y de modelo pulsando el nombre del modelo encima de la caja de chat. Para Anthropic, el modelo también se puede fijar en Ajustes → Anthropic API. Cada modelo lo factura el proveedor a su propio precio.

¿Puedo usar Ollama o LM Studio en vez de una API en la nube?

Sí (macOS). Abre Ajustes → Chat → Modelos locales, escribe la dirección del servidor (o déjala vacía para la de por defecto) y pulsa Conectar. Coucou comprueba que el servidor responde y lista los modelos disponibles. Para dejar de usarlo, pulsa Desconectar. No hace falta clave de API y es gratis: el modelo se ejecuta en tu Mac.

¿Funciona sin notch?

Sí. En un iMac, un Mac mini o un MacBook con la tapa cerrada sobre una pantalla externa, Mochi se coloca en una pequeña barra arriba de la pantalla principal. Con la tapa abierta, se queda en el notch.

¿Cómo se desinstala?

Quita antes los hooks: Ajustes → Claude Code → Desinstalar, y si los instalaste, también los de Gemini CLI y Antigravity. Si instalaste la línea de estado de uso del plan (Ajustes → Agentes → Uso del plan), pulsa ahí Desinstalar primero para recuperar tu línea de estado anterior. Después cierra la app y llévala a la Papelera. Si quieres, borra ~/Library/Application Support/NotchBuddy.

En Windows: el mismo botón Desinstalar para los hooks, y luego Configuración de Windows → Aplicaciones → Coucou → Desinstalar. Si quieres, borra %LOCALAPPDATA%\Coucou.

En Linux: el mismo botón Desinstalar para los hooks, y luego sudo apt remove coucou o sudo dnf remove coucou, o borra el AppImage.

Se instalou a linha de status de uso do plano (Configurações → Agentes → Uso do plano), clique em Desinstalar ali antes, para recuperar a sua linha de status anterior. Depois feche o app e mande para o Lixo. Se quiser, apague ~/Library/Application Support/NotchBuddy.

No Windows: o mesmo botão Desinstalar para os hooks, e depois Configurações do Windows → Aplicativos → Coucou → Desinstalar. Se quiser, apague %LOCALAPPDATA%\Coucou.

No Linux: o mesmo botão Desinstalar para os hooks, e depois sudo apt remove coucou ou sudo dnf remove coucou, ou apague o AppImage.
