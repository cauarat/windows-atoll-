A tiny friend that lives in your notch

Notchy watches your AI coding agents — Claude Code, Codex, Cursor, Gemini CLI, Antigravity and more — lets you approve Claude Code and Codex requests from the notch, chat with Anthropic, Google AI or OpenAI, and keeps an eye on Stripe, GitHub, Vercel, n8n and more. Free and open source.

Download for MacView on GitHub
Private by design. No account, no analytics, no tracking. Your keys stay in your Keychain, Windows Credential Manager or the Linux Secret Service. Read the privacy policy.

Requires macOS 15 or later. No notch? Mochi sits in a small bar at the top of the screen. Notchy is also on Windows 10 and 11. On a Mac it is not signed with an Apple Developer ID, so the first open needs one click in System Settings — the download page has the steps, and a one-line install that skips them. Linux: the AppImage, .deb and .rpm build from the same source under windows/, with no release published yet.
